# Margin Notes

A little room for your thoughts. Margin Notes is a responsive, browser-based notes app built for the Syntecxhub Web Development Internship Week 1 assignment.

## Features

- Create, edit, and delete notes with an accessible confirmation step.
- Search note titles and bodies.
- Keep notes in browser `localStorage` between visits.
- Responsive desktop and mobile layouts.
- Keyboard-friendly controls, focus management, and clear empty states.

## Stack

React, Vite, JavaScript, CSS. Interface icons are original inline SVGs.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build` and preview it with `npm run preview`.

## Data and privacy

Notes are stored only in the current browser's local storage. There is no account, backend, sync, or backup; clearing browser data removes saved notes.
