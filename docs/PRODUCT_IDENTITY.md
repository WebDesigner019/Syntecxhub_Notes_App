# Product Identity — Margin Notes

**Working product name:** Margin Notes  
**App title:** Margin  
**Tagline:** A little room for your thoughts.  
**Project/repository name:** `Syntecxhub_Margin_Notes`

## Why this name

“Margin Notes” evokes quick personal thoughts captured alongside everyday work. “Margin” is short enough for an app title and icon, distinctive in the UI, and suits a calm notebook identity. Before any public commercial release, check domain/trademark availability; this internship submission can use the name as a project identity.

## Platform decision

Build a responsive React web app. It will run in desktop and mobile browsers and fit phone screens. Do not make an APK or native app for this assignment. A PWA install prompt can be considered later only after the core project is complete and the submission requirements are met.

## Visual identity direction

- **Tone:** thoughtful, warm, focused, quietly confident.
- **Palette:** paper `#F7F5F0`, ink `#232522`, muted olive `#73806B`, pale sage `#E8ECE4`, warm clay `#C77D5B`, border `#E5E1D9`.
- **Typography:** system sans-serif for controls and navigation; an expressive serif for the product wordmark and note titles to suggest a personal notebook. Prefer bundled/system font stacks so the UI does not depend on external font downloads.
- **Mark:** original CSS/SVG monogram “M” formed by two offset note pages or a small folded page corner. Build in code; no downloaded logo asset.
- **Surface design:** lightly warm canvas, paper-like note cards, thin borders, modest rounding, spacious editing canvas, restrained shadows. Avoid generic gradients and stock photography.

## Asset policy

No external image assets are needed for this notes utility. Use original CSS/SVG for the app mark and simple interface icons (inline SVG or CSS), with accessible labels. This keeps the UI crisp, lightweight, and licensing-simple. If a decorative illustration is later added to an empty state, create a small original vector illustration and keep it secondary to the note-taking task.

## Reference guidance

Mobbin search was attempted, but the connected account requires a paid plan. No Mobbin screenshots are being copied. Use general interface patterns—searchable note list, clear selected state, focused editor, accessible destructive confirmation—as inspiration, then implement an original visual system.
